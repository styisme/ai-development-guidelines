# Changelog

All notable changes to this specification will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-10-27

### Added

- Initial public release of the AI Development Guidelines.
- 8 language versions: 中文, English, 日本語, Español, Français, Deutsch, 한국어, Русский.
- 7 core sections: Accountability, Scope of Use, Generation and Review, Verification, Disclosure, Security and Compliance, Documentation and Traceability.
- `AI_DISCLOSURE.template.md` template for projects to copy.
- `DEVELOPMENT_CONSTRAINTS` template with honest disclosure for resource-constrained development.
