# Ограничения среды разработки и шаблон честного раскрытия

> Скопируйте этот шаблон в свой проект, отметьте и заполните в соответствии с фактическими условиями. Этот документ объясняет фактические условия разработки и границы ответственности этого репозитория.

## I. Среда разработки (Отметить применимое)

- [ ] Есть локальная IDE / SDK, возможна локальная компиляция
- [ ] Есть локальные инструменты diff, возможна построчная проверка
- [ ] Возможно выполнение lint / модульных тестов
- [ ] Стандартный процесс PR (fork → PR → review)
- [ ] **Полагается исключительно на облачную компиляцию CI (без локального инструментария)**
- [ ] **Разработка исключительно на мобильных устройствах / умных часах**
- [ ] **Прямой push в master (без процесса PR)**

> Неотмеченные пункты означают, что их **физически невозможно выполнить в этом репозитории**, а не то, что их "проигнорировали".

## II. Фактически реализованные механизмы (Отметить выполненное)

### Раскрытие информации
- [ ] Предоставляется `AI_DISCLOSURE.md` с объяснением объема и доли участия ИИ
- [ ] Ссылка на этот файл в верхней части README
- [ ] Сообщение о фиксации помечено `[ai-assisted]`

### Функции высокого риска
- [ ] Функции высокого риска отключены по умолчанию (на уровне кода, а не только в документации)
- [ ] Отдельный раздел предупреждений для функций высокого риска (см. `SECURITY.md` или эквивалент)
- [ ] Требуется явное повторное подтверждение перед использованием функций высокого риска

### Контрольные точки (Gates)
- [ ] **Выпуск только после успешной компиляции CI** (единственная автоматизированная контрольная точка в этом проекте)
- [ ] Артефакты выпуска имеют номера версий и теги
- [ ] `CHANGELOG.md` фиксирует каждое изменение

### Тестирование
- [ ] **Тестирование на реальных устройствах** (реальные физические устройства)
- [ ] **Тестирование на эмуляторе** (при отсутствии физических устройств)
- [ ] **Не тестировалось** (см. честное раскрытие ниже)

> Неотмеченные пункты означают, что у этого репозитория **нет условий для их выполнения**, а не то, что о них "забыли".

## III. Честное раскрытие

**Следующие ситуации должны быть указаны правдиво, без приукрашивания:**

- Если этот репозиторий **не проводил никаких тестов на реальных устройствах или эмуляторах**, укажите это здесь четко:
  > "Код в этом репозитории не тестировался на реальных устройствах. Успешная компиляция CI означает только то, что синтаксис и зависимости верны, но не то, что функции работают. Пожалуйста, оцените риски самостоятельно перед использованием."

- Если модуль **является конфиденциальным, но не проверенным**, отметьте его как `⚠️ Не проверено` в списке ниже.

- Если функция **включена по умолчанию** (что нарушает принцип "высокий риск по умолчанию отключен"), четко укажите причину.
